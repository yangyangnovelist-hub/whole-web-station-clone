# 不持有到结算：盘口上买入、盘口上卖出的大规模策略搜索（设计，2026-10-04 写死，跑之前提交）

## 为什么

之前几乎所有检验都是“买入后持有到结算”。多因子模型能预测币安方向（锁箱段 t = +4.0），但 8/07 起 5m/15m 按 Chainlink TWAP 结算，钱亏在结算口径上。买入后在结算前按买一卖出，赚的是 Polymarket 价格本身的变动，和结算规则无关。另外查两种无风险套利：Up 卖一 + Down 卖一 + 手续费 < 1（买两边、合并成 1 USDC）；Up 买一 + Down 买一 − 手续费 > 1（拆分 1 USDC、两边卖出）。

## 数据和分段

- **挑选**：kacho.io BTC 5m 每秒盘口（两边买一、卖一、挂单量、深度），3/24–5/18，约 1.57 万个市场；币安 BTCUSDT 1 秒 K 线。A = 3/24–4/25 挑选，B = 4/26–5/18 确认。
- **独立复核**：Hugging Face whodisidk BTC 5m/15m/1h 100 ms 盘口，5/25–8/29（GitHub 上跑），只检验 A、B 留下的冻结名单，一次。
- **前向**：GitHub 前向录制的毫秒盘口（10/01 起）。

## 执行（保守）

- kacho 标为 s 的行从 s + 1 起才可用；信号只用 s 及以前的 K 线和行。决定后再晚一行成交：在 s + 1 决定 → 按标为 s + 1 的行（s + 2 起可用）的卖一买；平仓同样晚一行，按买一卖。Hugging Face 和前向数据：决定后 0.5 秒按当时快照成交。
- 两腿都付 taker 费 0.07·p(1 − p)；买入时卖一、卖出时买一都至少 5 份，价格在 0.02–0.98。
- 同一变体在同一市场同时最多一笔仓位；最晚在剩 15 秒时按买一平仓（另设“持有到结算”对照）。
- 盈亏 = 卖出买一 − 买入卖一 − 两腿手续费，每份；标准误按市场聚类。

## 策略族（参数网格在代码里列全，报告里给出总变体数 N）

1. **币安动量短打**：过去 w 秒（1、3、5、10、30）币安涨跌超过 zσ（1.5、2、3）或 x 个基点，买该方向，持有 h 秒（2、5、10、20、30、60、120）或到中间价追上模型公允价，可加止损。
2. **公允价缺口收敛**：模型公允价 − 卖一 ≥ g（2–10¢）买入，中间价回到公允价 − ε 或 h 秒后卖出（H 的“提前下车”版）。
3. **Polymarket 自身回归**：w 秒内中间价变动 ≥ m（3–15¢）而币安几乎没动，反着买，回归或 h 秒后卖。
4. **Polymarket 自身动量**：中间价随币安同向变动后继续跟，h 秒后卖。
5. **盘口失衡**：买一挂单量、深度一边倒时买那一方，h 秒后卖。
6. **多因子模型（FACTORS.md 的滚动样本外预测）**：开盘时模型给的方向，开盘后买，持有到剩 120、60、30、15 秒按买一卖出（不吃结算口径的亏）。
7. **时段和价格档**：在剩 τ 秒时买某价格档的强势方或弱势方，τ′ 秒时卖。
8. **无风险套利扫描**：两种合并/拆分套利出现的次数、持续时间、可做数量、每天美元；Hugging Face 和前向数据上看 0.5 秒后是否还在。

## 判定（事先写死）

- A 段：每个变体单边 p < 0.05 / N（Bonferroni，N = 全部变体数）且每份 > 0，才进入 B。
- B 段：进入的 k 个变体，每份 > 0 且 p < 0.05 / k，才进入冻结名单。
- Hugging Face 复核：冻结名单的 k′ 个变体，每份 > 0 且 p < 0.05 / k′，才算通过；通过的再在前向数据上按同样规则检验。
- 每个族报告 A 段最好的几个（不论是否通过），只作描述。
