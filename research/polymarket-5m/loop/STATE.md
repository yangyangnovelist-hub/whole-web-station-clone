# 策略搜索循环：状态

每一轮：读这个文件 → 做“下一步” → 更新这个文件和 `ledger.csv` → 提交推送。

## 目标与停止规则（写死，不在循环中途改）

- **找到** = 某个策略在**从未用于挑选它**的留出数据上，扣费、按“下一次快照”成交后，精确 p < 0.05 / 20 = 0.0025，且至少 300 笔、每份净盈亏 > 0。
- 留出集总共只允许做 **20 次**检验（`obd.HOLDOUT_BUDGET`），每次先写进 `ledger.csv` 再读数据。20 次各按 0.0025 检验，整个循环误报一个“赚钱策略”的概率 ≤ 5%。
- 发现集上可以随便试，但每个网格点都记账；每个假设族只按事先写好的规则挑一个候选（`hypotheses.py`：≥ 300 笔里 p 最小的，且 p < 0.001、每份 > 0）去留出集。
- **停止**：找到（上面的标准）；或留出预算用完；或数据和思路都耗尽。停止时如实汇报，没找到就说没找到。

拿不到：Polymarket API、Hugging Face、Kaggle、Dune、Polygon RPC（网络策略拦截）。

**数据集下载**：`python -m loop.obd fetch`（`OBD_ROOT` 指定目录；约 200 MB）。容器回收后要重下。

**切分**（按时间，第一次跑策略之前定下）：
- 发现集：最后报价在 2026-07-10 至 08-05 的市场（约 11.4 万个有官方结果），只用 08-06 之前的报价；
- 留出集：最后报价在 2026-08-06 至 08-31 的市场（约 5.5 万个），只用 08-06 起的报价；
- 09-01 之后的市场暂时没有官方结果。数据集每天更新，结果补齐后可以当**第二个留出集**（从未被任何人看过）。

**成交假设**：同一场比赛（从 slug 取“联赛-队伍-日期”）只做第一笔（胜负、让分、大小分、球员数据的结果相关）；
`same` 按决策那次快照的价格成交（偏乐观），`next` 按下一次快照（≤ 10 分钟后）成交、比决策价差超过 1¢ 就算没成交（主要看这个）。
手续费按 Polymarket 2026-07 起的体育费率 `0.05·p·(1−p)`（加密 0.07）。点差 > 3¢ 的盘口不算“有强势方”。
