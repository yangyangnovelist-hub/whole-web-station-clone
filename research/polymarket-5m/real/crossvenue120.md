# CrossVenue-120：提前预测 + 可成交性联合模型

**结论：收益门槛通过，但提前预测机制未通过。** 收益门槛要求 8/17–29 与九月实录两段都至少 30 笔成交且按市场聚类的 95% CI 下界大于 0；机制门槛还要求完整模型在两段都优于去跨所特征和打乱跳动标签的对照。

目标是在本机决策之后、交易所源时钟 80–160 ms（中心 120 ms）发生的 Binance ≥1 bp 跳动。特征只使用决策时已经收到的 Binance、永续和 Polymarket 数据；订单按当时历史固定压单 250/50/150 ms，再加 5 ms 传输，在第一份可用盘口上按事先固定的限价判断成交。未穿透限价就是未成交。每笔最多 5 份。

公开 C 全部处于 50 ms 固定压单时期；九月处于当前 150 ms 时期，但其实录盘口已知偏旧。因此两段日收益都不能直接外推为当前实盘收益。

## 训练、选参和固定策略

- 训练 A：2026-05-25–2026-07-15，4,468,793 个候选。
- 选参 B：2026-07-17–2026-08-16，212,735 个候选；只在这里选择一次门槛。
- 锁定 C：2026-08-17–2026-08-29，1,727,008 个候选；九月另有 1,033,599 个候选。
- 固定门槛：跳动概率 ≥ 0.5382，成交概率 ≥ 0.75，预测净 edge ≥ 2¢，最多追 3¢。
- B 段选参结果：322 成交，净 edge +10.55¢/份，最多 5 份总收益 $+167.88。

- 双锁箱收益门槛：通过。
- 提前预测机制门槛：未通过；去掉跨所特征和打乱标签的对照没有变差，不能把收益归因于 CrossVenue-120。

九月带 Binance 永续的子集有 164,839 个候选；其提前预测 AUPRC 0.075，基准率 1.40%。

## 仍然不能从回测中假定的事情

- 公开 C 是 50 ms 压单制度且盘口为 100 ms 对齐快照；真实撮合时刻落在两帧之间时仍有离散误差。
- 九月是当前 150 ms 压单制度，但记录器盘口已知偏旧；同时给 Binance 源时间统一加 100 ms 到机延迟，这不是每笔实测延迟。
- 公开段的第二交易所是 Hyperliquid，九月带第二交易所的子集是 Binance 永续；跨域改善必须单列看，不能混称稳定收益。
- 回测知道卖一数量，但不知道同一 150 ms 窗口里其他 taker 抢走多少；5 份仍可能被竞争者吃掉。

因此，不部署 CrossVenue-120。双锁箱中的正收益只能作为独立 ValueFill 策略的研究线索，必须另行预注册并验证。
